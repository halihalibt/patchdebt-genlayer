# Visual direction — Starry Night study

PatchDebt uses an original, CSS-rendered homage to the visual language of Van Gogh's *The Starry Night*: cobalt and ultramarine fields, moonlit ochre, sweeping orbital brush-like forms, layered night hills, and breathing stars. It does not reproduce the painting as an image asset. Motion is deliberately slow and ambient, with `prefers-reduced-motion` support.

The interface combines this painterly field with a restrained technical ledger: compact monospace labels, explicit evidence quotations, clear status colors, and a visible offline/verification boundary. The visual layer must never imply that demo results are finalized on-chain.
