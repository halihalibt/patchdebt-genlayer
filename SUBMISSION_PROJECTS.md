# Migration Coverage Desk — review reference

## Project description

PatchDebt turns software migration obligations into an evidence ledger. Compare a guide with an explicit change list, inspect exact quotations and explanations, and export a finalized GenLayer assessment with its transaction evidence. PatchDebt evaluates documentation coverage. It does not prove software compatibility, authenticate a source URL or establish that the supplied change list is complete. Semantic judgments remain model-dependent.

## Usage

Verify source, connect a Studionet wallet, enter migration inputs and a fresh request ID, then sign once. Recheck until finalized, inspect evidence and export the dossier. Existing manifest-linked records can be verified and exported without signing.
